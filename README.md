# SQL Practice and Case Studies

## About This Repository

This repository contains my SQL practice exercises and case studies completed to improve my SQL skills and understand how SQL is used to solve real-world business problems.

## What I Practiced

* Writing SQL queries to retrieve and analyze data
* Filtering and sorting data using `WHERE` and `ORDER BY`
* Aggregate functions such as `SUM`, `AVG`, `COUNT`, `MIN`, and `MAX`
* Grouping data using `GROUP BY` and filtering groups using `HAVING`
* Joining multiple tables using different types of JOINs
* Using subqueries and Common Table Expressions (CTEs)
* Working with window functions
* Analyzing business data and answering questions using SQL

## Case Studies

### AdventureWorks

Worked with the AdventureWorks dataset to practice SQL queries and explore business data. The case study helped me apply SQL concepts to analyze data and answer business-related questions.
